# Task 2: High-Fidelity UI Design

**Domain:** UI/UX Design  
**Internship:** CodeAlpha — Month 1

## Overview
Conversion of Task 1 wireframes into a high-fidelity UI design for the "FoodieApp" food delivery mobile app.

## Design System
- **Brand color:** #FF6B35 (orange) with dark #E85A24 and soft #FFF1EC
- **Background:** #F7F8FA, Cards #FFFFFF
- **Text:** #1F2937 (primary), #6B7280 (muted)
- **Success:** #10B981, Star: #FBBF24
- **Typography:** Inter (400/500/600/700/800)
- **Radius:** 16px cards, 12–14px inputs/buttons
- **Shadows:** soft elevation 0 8px 24px rgba(0,0,0,.06)

## UI/UX principles applied
- Visual hierarchy (bold titles, muted metadata)
- Consistent spacing (8/12/16/20px scale)
- Clear affordances (buttons, chips, qty steppers)
- Feedback states (active nav, badges, discount color)
- Accessibility: sufficient contrast, tappable targets ≥36px
